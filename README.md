# Scan & Go

ระบบสแกนสินค้าและจัดการร้านโชห่วย รองรับการสแกนเพิ่มสินค้าด้วยมือถือ

## Development

ต้องใช้ Node.js และ npm

```sh
git clone https://github.com/JntnCH/90s-mom-and-pop-shop.git
cd 90s-mom-and-pop-shop
npm ci
npm run dev
```

## Deployment

โปรเจกต์นี้คงการ deploy บน Railway ตามการตั้งค่าใน `railway.toml` และ `Dockerfile`
